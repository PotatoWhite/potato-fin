> **예측 기반 대응 원칙**: 이 보고서의 핵심은 **예측(prediction) → 예측에 대한 대응(response)**이다.
> 예측 없는 대응은 맹목이고, 대응 없는 예측은 공허하다. 둘 다 반드시 포함한다.
> - 모든 이벤트 → **결과 예측 + 확률 + 가격 영향** → **결과별 구체적 대응 액션**
> - 모든 정치/통상 이슈 → **시나리오별 포트폴리오 영향($)** → **시나리오별 매매 계획**
> - 모든 종목 분석 → **구체적 가격 예측(5거래일/1~3개월/6~12개월)** → **가격 도달 시 액션(매수/매도/홀드 조건)**
> - 모든 리스크 → **발생 확률 + 발생 시 손실 추정** → **헷지 방법 + 손절 기준**
> - "모니터링 중", "주시 필요", "지켜볼 것" 같은 회피성 표현 금지.
> - **형식**: "X가 Y확률로 Z가 된다 → 그러면 A종목을 B가격에 C수량 매수/매도한다"
