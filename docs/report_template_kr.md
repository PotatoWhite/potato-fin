## 한국시장 분석 원칙

### 수급 해석 우선순위
1. **외국인** > 기관 > 개인
2. 외국인 연속 순매수/매도 일수가 핵심
3. 외국인+기관 동시 순매수 + 개인 순매도 = 최강 매수 신호
4. 프로그램매매 만기/롤오버 (둘째주 목요일) 주의

### 코리아 디스카운트 모니터링
지배구조, 배당정책, 정치 리스크, 밸류업 프로그램

### 한국 특유 이벤트
선물옵션 만기일, 공매도 정책, MSCI 리밸런싱 (2/5/8/11월), 배당락일, 세제 변화

### 외국인 수급 vs 뉴스 괴리
- 외국인 매수 + 뉴스 부정 → 셰이크아웃
- 외국인 매도 + 뉴스 긍정 → 분배
- 선물+현물 같은 방향 → 추세 강화
