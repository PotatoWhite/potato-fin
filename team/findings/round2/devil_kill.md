### Alt C: "1종목 1페르소나" 집중 체제 (내가 창의로 제시)

**핵심 아이디어**: 보고서 19종목 전수조사 대신, **가장 자기기만이 심한 3종목만 매주 집중 리뷰**.

**구성**:
- Tier 3 일일 US/KR 보고서 **폐기**
- 대신 **"Deep Dive 3"**: 매주 금요일 Sonnet으로 **아래 3종목만** 집중 분석
  1. **최대 비중 종목** (현재 GOOGL 24.9%) — 리밸런싱 필수 이슈
  2. **최악 예측 적중률 종목** (thesis.json에서 자동 선택) — 편향 교정
  3. **최근 7일 최대 변동 종목** — 행동 필요성 높음
- 각 종목 × 5 페르소나 (PM/퀀트/아키텍트/트레이더/수아) 순차 리뷰 → 1 문서
- Tier 1 유지, flash 유지, 주간 매크로 요약은 Haiku (월 $3)

**월 비용**:
| 항목 | 단가 | 월 실행 | 비용 |
|------|------|---------|------|
| Deep Dive 3 (Sonnet, 3종목 × 5페르소나) | $6 | 4회 | $24 |
| 주간 매크로 (Haiku) | $2 | 4회 | $8 |
| flash | $0.40 | 10회 | $4 |
| Tier 1 | $0 | - | $0 |
| **합계** | | | **$36/월** |

**절감: $644 → $36 = 월 $608 (94% 감소, Alt A와 동일)**

**Alt A와의 차별점**:
- Alt A는 "모든 19종목 얕게"
- Alt C는 "3종목 깊게, 나머지 16종목 Tier 1 모니터링만"
- **Pareto**: 포트폴리오 가치의 60%+가 상위 5종목에 있다 (GOOGL 25% + MSFT/NVDA/PLTR/TSLA). 하위 14종목은 일일 분석 불필요.

**포기하는 것**:
- 19종목 매일 전수조사 (이건 사실 읽지도 않았다)
- "오늘 1억이 있다면" 섹션 (유희용이다)

**지키는 것**:
- 문제 종목에 대한 **깊이 있는** 판단
- 5 페르소나 교차검증 (self-consistency 활용)
- 비용 효율
- **측정가능한 이점**: 주당 3종목 × 월 4주 = 월 12 종목-회. 19종목 × 매일 21영업일 = 월 399 종목-회 대비 33배 효율적이면서도 **집중도는 올라감**

**위험**:
- "다른 종목은 어쩌지?" → Tier 1이 급변 감지 시 flash 트리거
- 사용자가 Deep Dive 3 선정 로직에 불만 가능 → 하지만 규칙 기반이면 반박 불가

## 4. 나의 1개 추천: **Alt C (Deep Dive 3)**

### 근거

**Alt A를 배제한 이유**:
- 주간 전수조사도 여전히 "얕음의 저주"다. Sonnet × 19종목 = 여전히 읽지 않는 보고서다. 비용만 줄었지 **의사결정 질은 그대로**.

**Alt B가 이론적으로 최적이지만 배제한 이유**:
- 연 $7,668 SPY 적립이 수학적으로는 맞다.
- **하지만 포트폴리오가 GOOGL 24.9% 편중 상태**에서 아무런 분석 개입 없이 방치하면, 단일 종목 리스크가 예상치 못한 방향으로 폭발할 때 **$7,668보다 훨씬 큰 손실** 가능.
- 구조적 리밸런싱 결정에는 **누군가는** 매주 한 번 "GOOGL 지금 팔아야 하나?"라고 물어봐야 한다. Tier 1은 질문하지 않는다.

**Alt C가 이기는 이유**:
1. **비용**: $644 → $36 (94% 감소) — Alt A와 동일
2. **의사결정 질**: 3종목에 집중 → 실제 행동 가능한 깊이
3. **자기기만 저격**: 선정 기준이 "최대 비중 + 최악 적중률 + 최대 변동" = **불편한 진실만 다룬다**
4. **63일 사일런트 다운 재발 방지**: 주 1회는 주 5일보다 heartbeat 가시성 높음 (못 나오면 티가 크게 난다)
5. **Vanity metric 탈피**: "보고서 몇 개 생성됨" 같은 숫자 대신 "GOOGL 비중 몇 % 줄였나"가 KPI가 됨

### 현재 시스템이 주는 것 vs Alt C에서 빠지는 것

| 현재 시스템 기능 | Alt C | 판정 |
|----------------|-------|------|
| 매일 52+건 WebSearch | ❌ | 결과: 29.4% 적중률. **없어도 된다**. |
| 일일 "오늘 1억이 있다면" | ❌ | 사용자가 매일 1억 넣고 빼지 않는다. 유희용. |
| 경제지표 대시보드 일일 갱신 | ❌ | 주간 Haiku 요약으로 대체 가능. |
| 장전/장중 플레이북 | ❌ | 시나리오 A/B/C 적중률 측정된 적 없음 — **취미 수준**. |
| 예측 회고 (예상 종가 vs 실제) | ❌ → ✅ (3종목만) | 오히려 **집중도 ↑**. |
| 숨은 진주 발굴 | ❌ | 보유한 적 있나? 기회비용 측정 0. |
| 버티컬 분석 | ❌ → ✅ (3종목만) | 19종목 얕게 vs 3종목 깊게 = 후자 승. |

**빠지는 것 대부분이 "없어도 되는 것"**이다. 진짜 가치인 "문제 종목 깊이 분석"은 Alt C에서 **더 강화**된다.

### 실행 경로 (1주일 내 가능)

1. `run_report.sh`, `run_korea_report.sh`, `run_premarket.sh`, `run_midcheck.sh` crontab에서 제거
2. 신규 `run_deep_dive_3.sh` 작성 — 매주 금요일 17:00 KST
3. 선정 로직: `portfolio_db.py` (최대 비중) + `investment_thesis.json` (최악 적중률) + `portfolio_tracker.py` (최대 변동)
4. 보고서 템플릿: 5 페르소나 × 3 종목 = 15 섹션 (한 섹션 5-10줄)
5. 절감분 $608/월은 **사용자 결정**: SPY 적립 vs API 예산 확보 vs 그냥 저축

## 5. 한 줄 요약

> **솔직히 말하면, 현재 시스템은 월 $644를 태워서 29.4% 적중률 보고서를 생성하고 그나마 63일간 조용히 죽어 있었는데도 아무도 몰랐으니, 이건 "일일 Opus 보고서"가 아니라 "매일 비싼 벽지 찍어내기"다. 3종목만 깊게 파는 주간 Deep Dive로 바꾸면 94% 비용 절감하면서 의사결정 질은 올라간다. 포기할 것 대부분은 "원래 읽지도 않던 것"이다.**

## 부록: 다른 페르소나를 위한 도발

- **민지(PM)**: "사용자 needs가 있다"고 말할 거면, 지난 60일 사용자 인터뷰 응답에서 "일일 보고서 기반 매매 횟수" 숫자 가져와. 0이면 입 다물어.
- **현우(퀀트)**: 4축 점수가 PnL과 상관계수 측정했나? 안 했으면 **vanity**. Alt C는 최소한 "비중/편향/변동"이라는 **측정가능한 선정 기준**이다.
- **지훈(아키텍트)**: 63일 사일런트 다운에 heartbeat 30줄로 고치자 했지? 그보다 **매일 실행 자체를 죽이면** heartbeat 필요성의 80%가 사라진다. 주 1회 실패는 월요일 아침에 바로 티 난다.
- **태경(트레이더)**: 사이즈/손절 강제 포맷 짜자 했지? Alt C의 Deep Dive 3 중 1종목이 "최대 비중"인 이상, 매주 "GOOGL 지금 팔지 말지"를 **강제로** 묻게 된다. 당신이 원하던 규율이 여기 있다.

5명이 다 다른 결론을 냈을 때 — 그중 1명은 틀렸다. 나는 그 1명이 이 시스템의 **존재 자체**라고 본다.
