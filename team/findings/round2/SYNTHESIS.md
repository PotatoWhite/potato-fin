## 🔥 Round 2 핵심 발견 3가지 (Round 1보다 심각)

### 1. 적중률 수치 자체가 **거짓말쟁이** (현우)
시스템은 **세 개의 서로 다른** 방향성 적중률을 동시에 내보낸다:
- `global.direction_rate`: **47.1%** (17건 중 8건)
- `bias_tracker` 합산: **33.1%** (25.1건 중 8.3건)
- Round 1 수아 인용: **29.4%** (현 thesis.json 어디에도 없음)

그리고 모든 19종목 `n < 10` → **통계적으로 무의미**. 삼성/SK하이닉스는 bias_tracker 자체가 없음. `update_thesis.py`가 `n_predictions=1.9`, `direction_hits=0.3` 같은 분수 값을 누적하는 **버그**. 즉, 수아가 Round 1에서 근거로 삼은 "29.4%" 자체도 확정된 사실이 아니라 **시스템의 자가당착**의 한 단면.

### 2. 월 비용은 $300이 아니라 **$644** (수아)
Round 1에서 수아가 "$300"이라고 한 건 과소평가. Tier 1~3 + 장전/장중 + 개선 루프 실측:
- Tier 3 US: $262.5/월, Tier 3 KR: $189/월
- Tier 2 premarket/midcheck: $73.5씩 = $147/월
- 개선 루프: $42/월, flash + Tier 1: $4/월
- **합계 $644.5/월 = 연 $7,734 (≈ ₩1,160만)**

NAV ₩2.14억 기준 **연 5.4% 드래그**. 더 황당한 것: 2/17~4/21 63일간 Tier 3 사일런트 다운이었으므로 실제 지출은 더 낮았지만, 그 기간 "돈 낸 서비스를 받지도 못한" 상태였음.

### 3. heartbeat 코드 **배포 준비 완료** (지훈)
지훈이 `check_heartbeat.sh` 실제 작성 + chmod +x. `run_report.sh`/`run_korea_report.sh` diff 제시. cron 1줄 추가하면 Tier 3 사일런트 다운 25시간 내 텔레그램 감지. **즉시 배포 가능.**

## 🎯 즉시 실행 가능 액션 5개 (우선순위 순)

### #1 — heartbeat 배포 (지훈, 30분)

2. `crontab -e` 에 1줄 추가: `0 * * * * ~/Spaces/finspace/potato-fin/check_heartbeat.sh >> ~/logs/stock-monitor/heartbeat.log 2>&1`
3. 수동 1회 실행으로 초기 alert 검증

**결과**: Tier 3 사일런트 다운 25시간 내 감지.

### #2 — 사용자 인터뷰 실행 (민지, 10분)
사용자(너)가 `pm_interview.md` 10문항 답변. 특히 **Q1 (지난 2개월 실제 매매 수)** 이 전체 시스템 방향을 결정.

**결과 시나리오**:
- Q1 = 0 → Alt B (완전 폐기) + SPY 적립 확정
- Q1 ≥ 1 AND Q2 < Q1 → 알파 있음, Alt C + 태경 포맷 조합 시도
- Q1 ≥ 1 AND Q2 = Q1 → 보고서 없어도 같은 매매 = 확증편향, Alt B 고려

### #3 — thesis.json 재구축 (현우, 30분)
```bash
.venv/bin/python3 update_thesis.py --init
```
소수 `n_predictions` 버그 조사 후 정수로 재계산. 텔레그램 `/ac` 출력에 "측정 불가 (n=X)" 라벨 강제 — 사용자가 가짜 47.1% 보고 판단 못 하게.

### #4 — portfolio_config.json 확장 (태경, 5분)
- `currency_exposure` 신규 (자산 통화 비중)
- `dry_powder` 신규 (USD/KRW 현금 별도)
- `risk_profile`에 `single_trade_risk_pct: 0.003`, `position_sizing_method: vol_target`, `min_cash_pct_usd: 0.05` 추가

**결과**: 보고서 헤더에서 "현금 21.6%" 환상 제거, 실제 dry powder 표기.

### #5 — Alt C 파일럿 (수아 + 태경 합의, 1주)

- 매주 금요일 1회, Sonnet, 3종목 × 5 페르소나
- 태경 액션 박스 포맷 필수 적용
- 비용: 주 $6 + Haiku 매크로 $2 = 월 $36

**결과**: 월 $644 → $36 (94% 절감) + 포지션 사이징 자동 강제.

## 🤔 "운영에 팀 더 필요한가?" — 너의 질문 답변

**결론: 지금은 No. 하지만 1개 팀 검증 후 방향 있음.**

### 현재 상태 냉정하게
- 5 페르소나 진단 팀 = **이번이 첫 실험**. ROI 검증 안 됨.
- 기존 "보고서 생성 6 agents"는 페르소나 없는 anonymous — 품질 천차만별
- 리스크/개선/모니터링은 모두 Python 자동화로 해결 중 (LLM 팀 불필요)

### 구조적으로 가능한 추가 팀 4개 평가

| 후보 팀 | 필요성 | 대안 | 판정 |
|--------|-------|------|-----|
| **보고서 생성 팀 (페르소나화)** | 현재 6 anonymous agents 품질 문제 | Alt C에서 이 팀을 주 1회만 돌리면 비용 해결됨 | **Alt C로 재구성 → 이게 답** |
| **리스크 팀** | 태경이 gap 지적 | `portfolio_config.json` + `price_alerts.py` 코드로 해결 (LLM 불필요) | ❌ 팀 불필요 |
| **개선 팀 (Sonnet 단독 → 팀)** | 현재 single Sonnet | 자기개선 루프는 이미 작동 중, 팀 필요 없음 | ❌ 팀 불필요 |
| **진단 팀 (현재) 정기화** | 이번 1회성 실험 | 월 1회 자동 실행 (현재 5 페르소나 재사용) | ⚠️ 추후 고려 |

### 권장 순서
1. **지금**: 이 5 페르소나 1팀 검증. Round 2 딜리버러블 배포 후 실제 가치 측정.
2. **1개월 후**: 보고서 생성을 **Alt C Deep Dive 팀**으로 재구성 (기존 5 페르소나 재활용 가능).
3. **3개월 후**: 현재 진단 팀을 월 1회 자동 실행하도록 cron 등록 (셀프 진단).

**팀 수 늘리지 마라. 팀 재활용하라.** — 이게 토큰 비용 대비 ROI 최대화 경로.
